## Inclusion criterion

A repository belongs scientifically under Revisics when its primary research object can be stated in the form:

\[
\boxed{\text{How does a transformation of the system change which future transformations remain possible?}}
\]

If a repository merely supplies software, measurement, provenance, or experimentation infrastructure, it should be labeled infrastructure.

If its primary object is neighboring but does not instantiate the recursive transformation-of-transformability question, it should remain adjacent.

This boundary is intentional. Revisics is not a synonym for every project in this account.
